Open a lab folder above to view its submission files. Depending on the lab, these include source code, tests, reports, UML diagrams, screenshots, and demonstration recordings.

Setup instructions and test commands are provided in the relevant lab documentation. Run Python commands from the corresponding lab folder, since some labs contain modules with the same filename.
